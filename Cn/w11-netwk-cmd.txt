WEEK 11: BASIC NETWORKING COMMANDS

1. ipconfig

Command:
ipconfig

Shows:
Displays IP address, subnet mask and default gateway.

Expected Output:
IPv4 Address  : 192.168.1.10
Subnet Mask   : 255.255.255.0
Default Gateway : 192.168.1.1


2. ipconfig /all

Command:
ipconfig /all

Shows:
Displays detailed network configuration including MAC address, IP address, DNS and DHCP.

Expected Output:
Physical Address : XX-XX-XX-XX-XX-XX
IPv4 Address     : 192.168.1.10
DHCP Enabled     : Yes
DNS Servers      : 192.168.1.1


3. ping

Command:
ping google.com

Shows:
Tests connectivity between the computer and the destination.

Expected Output:
Reply from 142.250.xxx.xxx: bytes=32 time=20ms TTL=117
Reply from 142.250.xxx.xxx: bytes=32 time=18ms TTL=117


4. tracert

Command:
tracert google.com

Shows:
Displays the path and number of hops taken to reach the destination.

Expected Output:
Tracing route to google.com
1    192.168.1.1
2    10.x.x.x
3    xxx.xxx.xxx.xxx


5. nslookup

Command:
nslookup google.com

Shows:
Finds the IP address of a domain name using DNS.

Expected Output:
Name:    google.com
Address: 142.250.xxx.xxx


6. netstat

Command:
netstat

Shows:
Displays active network connections.

Expected Output:
Proto  Local Address       Foreign Address      State
TCP    192.168.1.10:5000   xxx.xxx.xxx.xxx:443  ESTABLISHED


7. arp -a

Command:
arp -a

Shows:
Displays IP addresses and their corresponding MAC addresses.

Expected Output:
Internet Address    Physical Address
192.168.1.1         XX-XX-XX-XX-XX-XX


8. hostname

Command:
hostname

Shows:
Displays the computer's hostname.

Expected Output:
DESKTOP-ABC123


9. getmac

Command:
getmac

Shows:
Displays the MAC address of the computer.

Expected Output:
Physical Address
XX-XX-XX-XX-XX-XX
